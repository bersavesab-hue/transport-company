# 运输公司模拟器：长期开发基础骨架

当前版本：`foundation-0.1.0`

本仓库先固定游戏规则边界、模块接口、数据格式、存档迁移和资源管理方式。此阶段不制作正式界面，不批量生产图片，也不把城市、车辆、货物写死进程序。

## 核心定位

一张持续变化的运输地图，每辆运输单位都有完整生命周期，每条线路都会受到需求、竞争、成本、天气和运力变化影响。

首要玩法闭环：

1. 查看动态订单。
2. 选择并组合货物。
3. 分配车辆与司机。
4. 规划多站线路。
5. 处理运输过程事件。
6. 完成交付与财务结算。
7. 寻找返程订单，降低空驶率。

## 目录说明

- `docs/`：不可绕过的设计与架构规则。
- `schemas/`：内容数据的 JSON Schema。
- `data/`：示例内容包；以后新增内容只能走内容包。
- `src/core/contracts/`：规则核心对外协议。
- `scripts/`：内容一致性校验。

## 立即验证

安装 Node.js 18 或更高版本后执行：

```bash
npm run validate
```

校验包括重复编号、无效引用、数值边界、路线端点、内容包归属和存档版本。

## 第一阶段完成条件

- 6 个测试城市形成可运行路网。
- 同时存在 8 个动态订单。
- 一辆车可以承接、拼货、规划多站路线并完成结算。
- 统计载重率、空驶率、准时率、收入、成本和净利润。
- 旧存档通过迁移器升级，不要求玩家删除存档。

正式开发前必须阅读根目录 `AGENTS.md` 与 `docs/` 中的全部文件。
