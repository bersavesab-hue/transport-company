# 游戏设计基线

## 玩家体验承诺

玩家不是等待车辆自动赚钱，而是在不断变化的运输市场中，把空车变成满车，把亏损线路调整成有效网络，并保护公司现金流。

## 四个主爽点

1. **返程不空车**：发现返程订单后，路线由灰转绿，预计利润立即变化。
2. **调度聪明感**：通过拼货、多站、中转和换车提高装载率，而不是依赖升级按钮。
3. **资产有生命**：每辆车记录里程、司机、事故、维修、贷款、收入和退役历史。
4. **地图被点亮**：总部、仓库、班线、车辆与多式联运线路持续出现在同一张地图上。

## 反馈频率

| 周期 | 必须出现的反馈 |
| --- | --- |
| 5—15 秒 | 新订单、预计利润变化、装载率变化 |
| 30—90 秒 | 拼满一辆车、路线调整、事件处理 |
| 3—5 分钟 | 完成运输、结算、车辆状态变化 |
| 10—20 分钟 | 买车、开线、获得新合同 |
| 1—3 天 | 建仓库、扩停车场、成立分公司 |
| 长期 | 解锁铁路、航运、航空和国际网络 |

## 第一可玩版本

### 测试网络

南阳、郑州、武汉、西安、合肥、长沙，共 6 个城市、9 条道路。

### 初始状态

- 现金：8,000,000 分，即 80,000 元。
- 车辆贷款：4,200,000 分，即 42,000 元。
- 4.2 米轻型货车：1 辆。
- 停车位：2 个。
- 普通道路货运资质：已取得。
- 客运资质：已取得，但没有客车。

### 必须可玩

- 订单市场持续保持 8 个有效订单。
- 订单具有重量、体积、装卸时间、截止时间、运价和货物限制。
- 同车可拼多个兼容订单。
- 玩家可安排多站路线并看到车辆沿路线移动。
- 结算油费、通行费、人工、维护损耗、违约和货损。
- 到达城市后可以接返程货。
- 显示单趟装载率、空驶率、准时率和净利润。

## 长期范围

### 地图容量目标

- 全国级枢纽：35 个。
- 地级运输节点：333 个。
- 重点县级节点：300 个。
- 港口：46 个。
- 铁路货运枢纽：60 个。
- 机场：82 个。
- 国际预留节点：120 个。

节点分级加载，任何视图不得一次显示全部标签。

### 解锁阶段

1. 初创运输户：轻型货运、基础客运。
2. 城市运输公司：仓库、调度员、维修场。
3. 区域运输公司：跨省、重卡、冷链和专业货运。
4. 全国运输集团：分公司、物流园、大客户合同。
5. 综合运输集团：铁路代理和港口运输。
6. 国际物流集团：船舶、航空和海外节点。
7. 全球运输联盟：多式联运、联盟与收购。

## 明确排除

- 纯点击接单后长时间等待。
- 无限生成需求和无限倒卖。
- 只靠购买更贵车辆提高收益。
- 同一黄金线路永久有效。
- 铁路、轮船和飞机只是更大载重的换皮车辆。
- 更新版本要求玩家重新开局。
