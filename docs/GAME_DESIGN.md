# 游戏设计基线

## 玩家体验承诺

玩家不是等待车辆自动赚钱，而是在不断变化的运输市场中，把空车变成满车，把亏损线路调整成有效网络，并保护公司现金流。

## 四个主爽点

1. **返程不空车**：发现返程订单后，路线由灰转绿，预计利润立即变化。
2. **调度聪明感**：通过拼货、多站、中转和换车提高装载率，而不是依赖升级按钮。
3. **资产有生命**：每辆车记录里程、司机、事故、维修、贷款、收入和退役历史。
4. **地图被点亮**：总部、仓库、班线、车辆与多式联运线路持续出现在同一张地图上。

## 反馈频率

| 周期 | 必须出现的反馈 |
| --- | --- |
| 5—15 秒 | 新订单、预计利润变化、装载率变化 |
| 30—90 秒 | 拼满一辆车、路线调整、事件处理 |
| 3—5 分钟 | 完成运输、结算、车辆状态变化 |
| 10—20 分钟 | 买车、开线、获得新合同 |
| 1—3 天 | 建仓库、扩停车场、成立分公司 |
| 长期 | 解锁铁路、航运、航空和国际网络 |

## 第一可玩版本

### 测试网络

南阳、郑州、武汉、西安、合肥、长沙，共 6 个城市、9 条道路。

### 初始状态

- 现金：8,000,000 分，即 80,000 元。
- 车辆贷款：4,200,000 分，即 42,000 元。
- 4.2 米轻型货车：1 辆。
- 停车位：2 个。
- 普通道路货运资质：已取得。
- 客运资质：已取得，但没有客车。

### 必须可玩

- 订单市场持续保持 8 个有效订单。
- 订单具有重量、体积、装卸时间、截止时间、运价和货物限制。
- 同车可拼多个兼容订单。
- 玩家可安排多站路线并看到车辆沿路线移动。
- 结算油费、通行费、人工、维护损耗、违约和货损。
- 到达城市后可以接返程货。
- 显示单趟装载率、空驶率、准时率和净利润。

### 路线经营 v0.5

- 同一车辆允许装载多个目的地的兼容订单。
- 路线核心在道路图上计算最短可达路径，再按就近顺序安排配送城市。
- 每抵达一个订单目的地立即结算对应订单，其余订单继续随车运输。
- 空车可以主动调往其他城市，产生真实道路成本、车况损耗和空驶里程。
- 车队档案显示运营里程、空驶率、累计净收益和每公里净利。
- 终点返程雷达只展示市场中真实存在的返总部订单，不虚构货源。

### 全国地图底座 v0.5.1

- 所有城市使用全国统一经纬度坐标，局部 `x/y` 坐标只保留兼容。
- 全国视角显示7个运营区域状态，区域视角显示城市、道路、车辆和货源。
- 华中为首个运营区域；华东、西北当前仅接入合肥、西安两个门户枢纽，其余区域保持锁定。
- 地图支持全国/当前区域切换、分级缩放和触摸拖动。
- 新区域通过内容包增加区域、城市和路线，不改变现有永久编号与存档。
- 公司最多同时经营两份大客户合同；匹配合同线路、方向和货物的真实订单获得协议运价加成。

### 多级路网地图 v0.6

- 地图占据调度页主要空间，经营面板放入可收起的底部抽屉。
- 全国、省域、县域、城区使用同一经纬度坐标连续缩放，不切换互不兼容的地图。
- 经营城市负责订单和结算；地图节点负责县城、乡镇与设施；道路路段负责实际折线和道路等级。
- 高速、国道、省道、县道和本地道路按缩放级别出现，当前视野外内容不参与渲染。
- 未展开的下级节点聚合到上级节点显示数量，避免全国标签重叠。

## 长期范围

### 地图容量目标

- 全国级枢纽：35 个。
- 地级运输节点：333 个。
- 县级运输节点：覆盖全国全部县级行政区，并按运营价值分批开放。
- 港口：46 个。
- 铁路货运枢纽：60 个。
- 机场：82 个。
- 国际预留节点：120 个。

节点分级加载，任何视图不得一次显示全部标签。

### 解锁阶段

1. 初创运输户：轻型货运、基础客运。
2. 城市运输公司：仓库、调度员、维修场。
3. 区域运输公司：跨省、重卡、冷链和专业货运。
4. 全国运输集团：分公司、物流园、大客户合同。
5. 综合运输集团：铁路代理和港口运输。
6. 国际物流集团：船舶、航空和海外节点。
7. 全球运输联盟：多式联运、联盟与收购。

## 明确排除

- 纯点击接单后长时间等待。
- 无限生成需求和无限倒卖。
- 只靠购买更贵车辆提高收益。
- 同一黄金线路永久有效。
- 铁路、轮船和飞机只是更大载重的换皮车辆。
- 更新版本要求玩家重新开局。
