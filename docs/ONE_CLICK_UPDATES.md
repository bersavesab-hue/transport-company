# 一键更新工具

工作流位置：`.github/workflows/apply-update.yml`。

## 只需安装一次

1. 在仓库页面选择 `Add file` → `Create new file`。
2. 文件名填写 `.github/workflows/apply-update.yml`。
3. 把提供的工作流内容完整粘贴进去，提交到 `main`。

## 手机更新步骤

1. 下载新版本更新包，并确认文件名是 `update.zip`。
2. 在 GitHub 仓库根目录选择 `Add file` → `Upload files`。
3. 上传 `update.zip` 并提交。
4. 打开 `Actions`，等待 `Apply Update ZIP` 显示绿色对勾。

工作流先检查压缩包，在临时副本里安装更新并执行项目的完整检查。全部通过后才覆盖新增文件、删除压缩包、提交并推送；失败时不会把半成品写进项目。日常更新不再需要打开 Codespaces。

## 安全边界

- 拒绝绝对路径、上级目录、`.git` 内容和符号链接。
- 更新包不能覆盖一键工具自身。
- 更新默认只新增或覆盖文件，不批量删除仓库内容。
- 一次只执行一个更新，避免两个版本同时覆盖。
- 更新包根目录必须直接是项目文件，不能额外套版本文件夹。
- 更新包最多 5000 个文件，解压后最多 250 MB。
