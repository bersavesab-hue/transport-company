# 手机实机测试

游戏已经随更新包生成手机网页版本，测试不需要在手机安装 Node.js、VS Code 或其他开发工具。

## 首次开启（只做一次）

1. 等 `update.zip` 的 GitHub Actions 出现绿色对勾。
2. 打开仓库 `Settings` → `Pages`。
3. 在 `Build and deployment` 中把 `Source` 设为 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/docs`，点击 `Save`。
5. 等待约 1—3 分钟，打开：`https://bersavesab-hue.github.io/transport-company/`。

## 像游戏一样使用

在安卓 Chrome 中打开测试地址，点击右上角菜单 → `添加到主屏幕`。之后可以从桌面全屏进入。

## 存档注意

- 存档保存在当前浏览器本机，正常更新网页不会删档。
- 不要清理该网站的浏览器数据，也不要用无痕模式长期游玩。
- 同一网址换到另一台手机不会自动同步存档；云存档会在后续独立模块实现。

## 每版测试重点

1. 选择同一城市中两个不同目的地订单，确认出现多站路线。
2. 发车并加速，确认每到一个城市只结算本站订单。
3. 点击地图上的另一城市，使用“空车调往”，确认现金下降且空驶率上升。
4. 购买第二辆车，确认两辆车能够独立接单和运行。
5. 刷新网页，确认现金、车辆位置、在途状态和订单仍然保留。
6. 在业务中心签订一份大客户合同，完成匹配订单并确认合同进度和运价加成增加。
7. 点击地图“全国”，确认出现7个区域状态；再切回“当前区域”，测试放大、缩小和手指拖动。
