# 数据协议

## 永久编号

格式：`类别_主体_序号`，全部使用小写 ASCII、数字与下划线。

示例：

- `city_nanyang_001`
- `route_nanyang_zhengzhou_001`
- `vehicle_model_light_truck_001`
- `vehicle_unit_000001`
- `cargo_electronics_001`
- `order_000001`
- `market_event_zhengzhou_express_001`

显示名称可以修改，永久编号不可修改或复用。

## 单位

| 数据 | 内部单位 | 显示方式 |
| --- | --- | --- |
| 金额 | 分，整数 | 元，两位小数 |
| 距离 | 米，整数 | 公里 |
| 重量 | 千克，整数 | 吨或千克 |
| 体积 | 升，整数 | 立方米 |
| 时间 | 游戏秒，整数 | 分钟、小时、日期 |
| 比例 | 万分比，整数 | 百分比 |

禁止用浮点数保存货币和核心比例。

## 引用关系

- 路线连接两个城市编号。
- 订单引用起点、终点和货物编号。
- 市场事件引用受影响城市和货物编号，并使用万分比记录需求变化。
- 大客户合同引用起点、终点和货物编号，并使用万分比记录协议运价加成。
- 车辆实例引用车辆型号编号和当前城市编号。
- 所有静态内容引用所属内容包编号。
- 存档只保存永久编号和变化状态，不复制车辆型号或城市静态数据。

## 内容包

每个内容包必须声明：

- 永久内容包编号。
- 语义版本。
- 最低游戏版本。
- 依赖内容包。
- 提供的城市、路线、车辆、货物、订单、市场事件和客户合同文件。

加载顺序由依赖关系决定，循环依赖直接拒绝。

## 兼容性

- 新增可选字段：兼容更新。
- 修改字段含义：不兼容，必须新增字段并迁移。
- 删除字段：先弃用一个存档版本，再迁移删除。
- 删除内容：标记 `active: false`，保留编号解析能力。
- 修改显示名称或图片：兼容，不改变编号。
