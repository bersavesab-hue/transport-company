# v0.6.2 地图与实机体验更新

- 进入地图默认聚焦当前车辆所在城市，而不是泛化区域中心。
- 点击城市/地图节点后自动聚焦并按节点层级放大。
- 地图拖拽/双指缩放使用 requestAnimationFrame 限帧，降低连续重绘卡顿。
- 桌面/触控板增加滚轮缩放。
- 路线状态拆分：蓝色虚线=选中城市预览路线；橙色虚线=已装货待发路线；青绿色实线=运输中实际路线。
- 标签优先级保留，并增加四方向避让及必要引导线。
- 修正短屏、窄屏和安全区布局；短屏自动隐藏非关键市场快讯，优先保证地图面积。
- 不修改存档版本（仍为 saveVersion 4），旧 v0.6.1 存档可继续读取。
